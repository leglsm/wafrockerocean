ⓘ Layout Placement Logic
CDEF Columns — Stacked Bottom Up
Each group fills C/D and E/F simultaneously from row 1 upward.
CD gets ceil(group÷2) rows, EF gets floor(group÷2) rows.
Stacking order: G65MP → G07MP → G07 RUNBRD → G07 LUX
After each group, both cursors sync to max(cdRow, efRow) to eliminate gaps.
B Column — Sequential Blocks
F95 LH rows 1–3 (4 colors/slot) → F95 RH rows 4–6 → F96 LH rows 7–9 → F96 RH rows 10–12 → G05 PRIMER LH rows 13–15 → G05 PRIMER RH rows 16–18
